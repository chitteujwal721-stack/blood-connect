# BloodConnect API

This package will contain the central NestJS backend API for BloodConnect.

## Roadmap Note

As per the Phase 1 master brief and architecture decisions:
- The NestJS API will be implemented in **Phase 2**.
- Phase 1 strictly focuses on the desktop application foundation, security boundaries, IPC bridge, navigation structure, and UI shell.
- No local database or mock backend exists in Phase 1.
